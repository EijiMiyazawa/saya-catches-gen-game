# さやさんを動かしてげんさんをキャッチするゲーム

さやさんを左右に動かして、上から落ちてくるげんさんを制限時間内にキャッチし、スコアを競うブラウザゲームです。

## 遊ぶ

ブラウザで遊べます：https://eijimiyazawa.github.io/saya-catches-gen-game/

## ご案内

本作品は、なつめさんちさんを題材とした非公式のファンメイドゲームです。なつめさんちさんの公式作品ではありません。

なつめさんちさんのご意向を尊重し、事情により予告なく公開を停止する場合があります。

## 素材の扱い

- このリポジトリには、ゲームを遊ぶために必要なビルド済みデータだけを置いています。
- ビルド済みデータには、イラスト・音源・フォントなどの素材が含まれます。素材の権利は、それぞれの作者・提供元にあります。
- 素材は、このゲームで使うためだけに組み込んでいます。データから素材を取り出して利用したり、再配布したりしないでください。
- このリポジトリには、ゲームのソースコードは含まれていません。
