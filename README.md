# さやさんを動かしてげんさんをキャッチするゲーム

さやさんを左右に動かして、上から落ちてくるげんさんを制限時間内にキャッチし、スコアを競うブラウザゲームです。

## 遊ぶ

ブラウザで遊べます：https://eijimiyazawa.github.io/saya-catches-gen-game/

PC・スマートフォンのブラウザで遊べます。

## 遊び方

さやさんを左右に動かして、上から落ちてくるげんさんをキャッチします。
げんさん 1 人につき 1 点です。落としても減点はありません。
制限時間は 60 秒です。残り時間（TIME）が 0 になったら終了です。

### 操作

| やりたいこと | キーボード | マウス・タッチ |
| --- | --- | --- |
| 音を出して始める（起動直後の再生マーク） | どれかのキー | 画面のどこでも |
| ゲームを始める | Enter / Space | START ボタン |
| さやさんを左右に動かす | ← / → | 画面の左右ボタン |
| ポーズ・再開 | Esc | ポーズボタン / RESUME |
| やり直す（ポーズ中・リザルト） | R | RETRY |
| タイトルに戻る（ポーズ中・リザルト） | Q | TITLE |

- 左右は、1 回押すごとにさやさんの幅の半分だけ動きます。長押しでは動き続けないので、押し直してください。
- START・RETRY のあとは「3・2・1」のカウントが終わってから始まります。
- ブラウザの別のタブに切り替えると、自動でポーズします。戻っても自動では再開しないので、Esc か RESUME で続けてください。
- BGM と効果音の音量は、ポーズ画面のスライダーで別々に変えられます。
